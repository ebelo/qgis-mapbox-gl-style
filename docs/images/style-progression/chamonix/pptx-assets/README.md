# PowerPoint assets

These five 1184 × 840 PNG cards are the independent components of the style-maturity matrix. They share the same geometry, typography, map crop, and transparent outer background.

Insert them into PowerPoint at the same size and position to reveal the progression one stage at a time, or arrange them as separate objects to reproduce the matrix natively.

The cards are generated from the source progression frames by:

```bash
python scripts/build_style_maturity_matrix.py
```
